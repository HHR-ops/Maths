# 计算模型与图形约定

## 卫星方向与参数

方位角 az 从北向东顺时针计，高度角 el 从水平面向天顶计。观测站处采用 E 东、N 北、U 上的局部直角坐标。

单位视线向量：

    e = cos(el) sin(az)
    n = cos(el) cos(az)
    u = sin(el)

未知参数为接收机位置改正与以米表示的接收机钟差：

    x = [δE, δN, δU, c·δt]ᵀ
    Gᵢ = [−eᵢ, −nᵢ, −uᵢ, 1]

第一版不引入系统间钟差、对流层参数或卫星轨道参数。卫星编号为示意编号，不代表实际 PRN；模型里的可拖动方向不是当前实际星座。

## DOP 与协方差

假定参与观测具有相同测距标准差 σρ，且各卫星的观测误差相互不相关：

    Cov(ε) = σρ² I
    Q = (GᵀG)⁻¹
    Cov(x) = σρ² Q

Q 的行列顺序为 E、N、U、c·δt。位置协方差取 Q 的左上 3×3 子阵并乘以 σρ²。

    HDOP = sqrt(qEE + qNN)
    VDOP = sqrt(qUU)
    PDOP = sqrt(qEE + qNN + qUU)
    TDOP = sqrt(qtt)
    GDOP = sqrt(qEE + qNN + qUU + qtt)

DOP 无量纲，由参与计算的方向几何决定。σρ 改变预测误差的长度尺度，不改变 DOP。这里的精度预测以模型和输入标准差为条件，不是对真实接收机误差的实测估计。

实现通过 G 的奇异值分解计算 Q = V diag(1/s²) Vᵀ，避免先构造法方程再直接求逆造成额外数值放大。

## 数量、秩与病态

至少四颗卫星是必要的数量条件，G 还需具有列满秩 4。程序把不大于最大奇异值 10⁻¹⁰ 倍的奇异值视为数值零，显示矩阵秩与奇异值。秩不足时不输出有限 DOP 或可逆协因数阵。

满秩时显示 G 的二范数条件数 smax/smin；超过 10⁴ 时提示几何接近退化。这是教学界面中的诊断阈值，不是行业通用质量等级。

同仰角构型的 −u 列为常数，与钟差列相关，因此本项目的八星同仰角示例秩为 3。增加同一构型下的卫星数量不能补足该缺失方向。

## 水平椭圆与三维椭球

水平协方差 CEN 的特征值 λmax、λmin 给出标准椭圆半轴 sqrt(λmax)、sqrt(λmin)。长轴方向按正北起顺时针表示，范围 0–180°；圆形时方位不唯一。

三维位置协方差 CENU 的三个特征值和特征向量给出三维标准椭球半轴及主轴方向。

在零均值多元高斯假定下：

| 区域 | 标准区域覆盖率 | 95% 半轴倍率 |
| --- | ---: | ---: |
| 二维椭圆 | 约 39.35% | sqrt(χ²₂,0.95) = 2.44774683 |
| 三维椭球 | 约 19.87% | sqrt(χ²₃,0.95) = 2.79548348 |

因此“标准区域”不能解释成统一的 68% 或 95% 区域。这里使用已知先验 σρ 的 χ² 倍率；没有通过残差估计后验单位权方差，不使用后验 F 倍率。

误差图可切换自适应或统一固定比例；A/B 始终共享物理范围和当前置信设置，各自保留 σρ。半轴数值保留实际米单位，固定比例超出图窗时会裁切。三维渲染把 ENU 映射为显示坐标 (E,U,−N)，半球是单位方向的示意，不按实际卫星距离绘制。三维标记与接收机模型有小幅视觉尺寸，主轴方向和数值取自实际协方差计算。

## 可见性筛选

筛选顺序为：手动停用、低于截止高度角、被遮挡、参与计算。高度角等于截止角时仍可参与。

遮挡扇区从起始方位角顺时针延伸指定宽度，可跨越 0°。落在扇区内且高度角不高于遮挡高度的卫星被排除；边界包括在遮挡区域内。扇区不模拟电磁传播、多路径或绕射。

天空图采用等角度径向投影 r = R(90°−el)/90°：中心为天顶，外圆为水平面。它是方向图，不是地面地图。

## 典型场景

均匀分布提供八个方向与多个仰角；集中一侧用同样数量展示几何差异；局部遮挡提供十二个方向和遮挡扇区；最少四星为一颗天顶星加三颗 20° 仰角、间隔 120° 的卫星；同仰角退化展示数量足够但不能分离高程与钟差的情况。

内置场景、模拟轨迹与遮挡均为教学构造。导入 SP3 后使用文件提供的地心位置历元，仍不作星历传播、真实卫星预报或多系统偏差估计。

## v0.2 噪声实验

对每个样本生成独立 ε ~ N(0, σρ²I)，通过 δx = G⁺ε 求解 ENU 位置误差及距离形式钟差；不进行原始伪距的非线性定位迭代。经验协方差用 1/(N−1) 的中心化样本估计，经验 PDOP 为 sqrt(trace(Csample))/σρ。

二维覆盖使用理论 CEN 的马氏距离，三维覆盖使用 CENU 的特征轴；阈值分别为当前区域的二维、三维倍率平方。不是用同一 χ² 倍率评估不同维度。样本均值和协方差估计与理论存在有限样本差异。

固定种子的伪随机数与 Box–Muller 变换保证同一场景可复现。场景变化后点云及统计失效；秩不足或条件数超过 10⁶ 时拒绝仿真。

## v0.2 SP3 方向转换

参照 [IGS SP3-d 格式规范](https://files.igs.org/pub/data/format/sp3d.pdf)，读取 c/d 版本的 P 位置记录；X/Y/Z 的 km 转为 m，速度、钟差与精度记录不进入本模型。

站点用 WGS84 椭球：a = 6378137 m，f = 1/298.257223563。将站点大地坐标转换为 ECEF，取卫星减站点的向量，再旋转至局部 ENU。方位角 atan2(E,N)，高度角 atan2(U,sqrt(E²+N²))。

只按文件离散历元选取，不作插值、光行时改正、轨道外推、时间系统转换或参考框架历元转换。时间标签保留文件声明，内部排序分辨率为毫秒；未声明则显示“未声明”。高精度应用需保证文件和站点框架兼容。

缺测零位置和异常占位位置跳过；重复卫星、无效日期、非递增历元、非有限坐标及超限文件拒绝导入。一次导入上限 12 MB / 4096 历元，每历元最多 256 位置；单星座地平线上场景最多 64 颗。闰秒 60 暂不接受。

一次仅选择一个星座，与当前单钟差模型一致。地平线以下位置移除后，再应用截止角和遮挡筛选。卫星钟差和各系统间偏差均未估计，不能把本结果解释为实际定位精度。
