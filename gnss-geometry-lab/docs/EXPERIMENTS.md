# 交互实验指南

## 几何与绝对精度

1. 保持“均匀分布”，保存一组对照。
2. 将测距 σρ 从 1 m 改为 2 m。
3. 打开“场景对照”：DOP 不变，当前场景的椭圆 / 椭球半轴变为两倍。
4. 旋转任一 A/B 画布，两侧相机同步。两侧使用相同米制范围与当前置信类型，σρ 保留各自设置。

日常观察可用自适应比例。需要连续比较时，切换统一固定比例，输入适当的误差半轴范围。范围过小会裁切误差区域，读取半轴数值并增大范围即可。

## 动态轨迹

打开“动态轨迹”，以当前编辑场景为起点观察独立方向变化。点击播放、暂停、单步或拖动实验进度；点击 DOP 曲线也可定位对应帧。曲线断点表示该帧的矩阵秩或卫星数量不满足解算要求。

轨迹是方向教学模型，进度百分比没有实际时标含义。所有方位角统一旋转会保持 DOP 不变，因此本工具分别改变每颗卫星的相对方向。

“采用当前帧”停止实验并生成一次编辑记录；撤销可回到实验前的编辑场景。“返回编辑场景”退出预览。保存项目、保存对照和导出始终针对当前显示帧。

## 噪声与覆盖率

打开“噪声实验”，设置 100–5000 个样本与 32 位非负整数种子，再运行实验。

每个样本向当前参与卫星施加独立 N(0, σρ²) 测距噪声，通过 G 的伪逆求位置误差。蓝色散点对应同一组 ENU 误差，分别叠加在三维与水平视图；表格给出无偏经验位置协方差。

标准椭圆的理论二维覆盖率约 39.35%，标准椭球的三维覆盖率约 19.87%；95% 设置分别使用二维、三维 χ² 倍率。经验覆盖率有有限样本波动，不会刚好等于理论比例。

改变方向、卫星筛选、σρ 或区域类型会使旧样本失效。固定种子与相同场景可复现；几何退化或过度病态时不运行实验。图窗之外的点未显示，但统计仍使用全部样本。

## SP3 文件与站点

导入本地 SP3-c/d 文本，或先点击“载入教学示例”体验流程。示例是本项目合成的五历元数据，不能用作真实卫星产品。

输入站点 WGS84 纬度、经度及椭球高，选择一个星座，然后拖动历元滑块或播放。地平线以下卫星被移除，截止角、遮挡仍继续筛选。SP3 原始位置单位 km，在内部转换为 m。

本版本只使用位置记录，忽略速度与卫星钟差。不插值、不外推、不转换时间系统；显示时间沿用文件声明，内部排序分辨率为毫秒。未声明时间系统的文件会明确显示“未声明”。不作地球参考框架的历元转换；高精度工程用途需自行保证站点与文件框架兼容。

为符合单一接收机钟差模型，一次仅计算一个星座。即使文件包含多个星座，也不会自动混用。

项目保存当前方向帧与对照，完整 SP3 和站点输入仅保留在本次会话。若要继续逐历元实验，需再次导入文件和设置站点；若只想编辑该几何，点击“采用当前帧”。

## 保存与退出

Ctrl+S 保存项目。v0.1 项目仍可直接打开；CSV 为数值结果，PNG 为当前主三维画布。噪声点云会进入 PNG，轨迹 / 覆盖率统计不单独导出，可用截图保留。

程序关闭不运行同步 JavaScript 保存回调；自动草稿为防抖保存，退出前需要确保成果时使用“保存项目”。视角、固定比例、撤销历史、轨迹状态和点云不进入项目文件。
