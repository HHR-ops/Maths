# 更新记录

## v0.2.0 — 2026-10-22

- 黑金主题、中性灰白文字、编号避让、ENU 视角、撤销与重做。
- 统一误差图比例，A/B 三维及椭圆对照、相机联动与指标差值。
- 独立模拟轨迹、播放 / 暂停 / 单步、轨迹线与 DOP 曲线定位。
