# 更新记录

## v0.5.0 — 2026-10-21

- 增加 XLSX / CSV / TSV 批量导入、列映射、单位转换与原子性校验预览。
- 为七类网生成可直接导入的 Excel 和 CSV 模板，支持 GNSS 相关协方差阵。
- 增加分步骤方程与矩阵展示、矩阵到观测/点的定位、迭代历史和四法对照。
- 增加先验尺度的整体 χ² 检验、标准化残差、相关观测块联合检验及 Holm 多重检验校正。
- 增加疑似异常观测的画布标记、停用复算、前后指标对比及撤销恢复。
- 扩充至 76 项 Python 测试、10 组浏览器测试，并验证打包后的 Excel、诊断与原生窗口流程。

## v0.4.0 — 2026-10-20

- 使用 React、TypeScript、Vite 重做本地桌面界面，统一字体、细边框、按钮与布局。
- 参考 shadcn-admin 与 shadcn/ui 的界面和组件模式，使用 Radix Dialog 与 Lucide 图标。
- 接入七类控制网的交互画布、控制点属性、观测编辑、撤销和实时模型统计。
- 接入条件平差、附参条件平差、间接平差及附限间接平差。
- 支持 GNSS 三维基线及完整协方差阵、精确限制、矩阵提取、法方程与协因数计算。
- 展示点位精度、相对精度、1σ 误差椭圆与高程误差棒，支持项目保存及成果导出。
- 使用 WebView2 和 PyInstaller 打包 Windows x64 单文件程序，并提供便携包。

## 历史版本

v0.1 至 v0.3 使用 Tk 界面。旧界面源码保留在 app.py、network_ui.py 与 ui_theme.py 中，当前开发入口为 desktop.py。
