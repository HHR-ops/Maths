# 更新记录

## v0.6.2 — 2026-10-22

- 将理论标题改为“n，t，r参数与基准亏损”，统一“参数个数”“独立限制条件个数”等计数表述。
- 润色十三篇理论的标题、摘要、符号解释、算例与提示，减少重复、生硬和口语化表述。
- 统一检验页面与报告的“未拒绝原假设”“未拒绝域”等表述，明确结果的统计含义。
- 将矩阵文本报告的 n/t/r 含义与界面对齐，参数个数另以 u 表示；先验与后验尺度采用明确标签。
- 同步更新离线手册，公式、数值算法与项目文件格式保持一致。

## v0.6.1 — 2026-10-21

- 优先使用 Windows 中文界面字体，加深正文、表头、数值、辅助标签与网形标注，统一文字层次。
- 细化按钮和输入框轮廓、面板与表格分隔线，改善悬停、选中、焦点和禁用状态。
- 统一为浅色圆角滚动条，移除上下箭头，支持滚轮与拖动；深色系统偏好下仍匹配浅色界面。
- 在 150% 缩放的真实 WebView2 窗口及三种宽度下检查；原有 14 组浏览器流程通过。

## v0.6.0 — 2026-10-21

- 增加离线理论与知识模块：六章十三篇，覆盖误差来源与统计规律、传播定律、最小二乘、统计与模型检验、成果质量与误差椭圆。
- 增加本地 KaTeX 公式与字体、全文检索、符号速查、手算例题、逐篇理解自测、参考资料链接。
- 增加正态概率、相关传播、加权平均、整体 χ² 检验、先验/后验置信椭圆五类交互例题。
- 为控制网和矩阵结果增加理论入口；阅读时保留当前计算成果，并显示当前控制网的解释摘要。
- 明确二维标准椭圆覆盖率、后验 F 倍率、先验检验尺度及相关观测的处理条件。
- 从同一内容生成离线理论手册，扩充至 87 项 Python 测试、14 组浏览器测试与 45 项打包计算检查。

## v0.5.0 — 2026-10-21

- 增加 XLSX / CSV / TSV 批量导入、列映射、单位转换与原子性校验预览。
- 为七类网生成可直接导入的 Excel 和 CSV 模板，支持 GNSS 相关协方差阵。
- 增加分步骤方程与矩阵展示、矩阵到观测/点的定位、迭代历史和四法对照。
- 增加先验尺度的整体 χ² 检验、标准化残差、相关观测块联合检验及 Holm 多重检验校正。
- 增加疑似异常观测的画布标记、停用复算、前后指标对比及撤销恢复。
- 扩充至 76 项 Python 测试、10 组浏览器测试，并验证打包后的 Excel、诊断与原生窗口流程。

## v0.4.0 — 2026-10-20

- 使用 React、TypeScript、Vite 重做本地桌面界面，统一字体、细边框、按钮与布局。
- 参考 shadcn-admin 与 shadcn/ui 的界面和组件模式，使用 Radix Dialog 与 Lucide 图标。
- 接入七类控制网的交互画布、控制点属性、观测编辑、撤销和实时模型统计。
- 接入条件平差、附参条件平差、间接平差及附限间接平差。
- 支持 GNSS 三维基线及完整协方差阵、精确限制、矩阵提取、法方程与协因数计算。
- 展示点位精度、相对精度、1σ 误差椭圆与高程误差棒，支持项目保存及成果导出。
- 使用 WebView2 和 PyInstaller 打包 Windows x64 单文件程序，并提供便携包。

v0.1 至 v0.3 使用 Tk 界面。旧界面源码保留在 app.py、network_ui.py 与 ui_theme.py 中，当前开发入口为 desktop.py。
